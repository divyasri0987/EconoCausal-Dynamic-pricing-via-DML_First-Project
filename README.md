# EconoCausal – Dynamic Pricing via Double Machine Learning

## Day 1: Project Introduction, Objectives, Tools & Technologies, and Workflow

## 1. Project Introduction

EconoCausal is a Data Science and Machine Learning project that focuses on understanding how discounts affect customer purchasing behaviour. The main aim of this project is to find out whether offering a discount actually influences a customer's decision to buy a product. Using Causal Inference and Double Machine Learning (DML), the project will analyse the impact of discounts on purchasing decisions. It will also explore how businesses can distribute discounts effectively within a limited marketing budget and make better pricing decisions based on data.

## 2. Objective

The main objectives of this project are:

• To understand how discounts affect customer purchasing behaviour.

• To analyse the relationship between discounts and purchase decisions.

• To estimate the actual effect of discounts using Causal Inference and Double Machine Learning.

• To find effective ways to distribute discounts within a limited marketing budget.

• To help businesses make better pricing decisions using data-driven insights.

## 3. Tools and Technologies

• Python: For data analysis and machine learning.

• Pandas and NumPy: For data cleaning, processing, and numerical calculations.

• EconML: For estimating the effect of discounts on customer purchasing behaviour.

• DoWhy: For analysing causal relationships.

• SciPy: For optimising discount allocation within a limited budget.

• Jupyter Notebook: For working with the dataset and performing analysis.

• React.js: For developing an interactive dashboard.

• Plotly: For creating interactive charts and visualisations.

• Git and GitHub: For managing project files and tracking progress.

## 4. Project Workflow

1. Dataset Collection: Download the dataset required for the project.

2. Data Exploration: Understand the dataset and identify its important features.

3. Data Preprocessing: Clean the data and handle missing values if required.

4. Causal Analysis: Study the relationship between discounts and customer purchasing decisions.

5. Double Machine Learning: Estimate the effect of discounts on purchase decisions.

6. Budget Optimisation: Explore how to allocate a limited discount budget effectively.

7. Data Visualisation: Create charts and visualisations to understand the results.

8. Dashboard Development: Develop an interactive dashboard to present the findings.

9. Results and Insights: Summarise the findings and identify useful insights for pricing decisions.

## 5. Expected Outcome

The expected outcome of this project is to understand how discounts influence customer purchasing behaviour and how a limited discount budget can be allocated more effectively. The project aims to help businesses make better pricing and marketing decisions using data analysis and machine learning.
