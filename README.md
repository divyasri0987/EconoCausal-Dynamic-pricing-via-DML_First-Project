##EconoCausal – Dynamic Pricing via Double Machine Learning

##Project Introduction:

EconoCausal is a Data Science and Machine Learning project that focuses on understanding how discounts affect customer purchasing behavior. The main aim of this project is to find out whether offering a discount actually influences a customer's decision to buy a product. Using Causal Inference and Double Machine Learning (DML), the project will analyze the impact of discounts on purchasing decisions. It will also explore how businesses can distribute discounts effectively within a limited marketing budget and make better pricing decisions based on data.

##Project Objectives:

• To understand how discounts affect customer purchasing decisions.

• To analyze and prepare the required data.

• To study the relationship between discounts and customer purchases.

• To estimate the impact of discounts using Double Machine Learning.

• To explore ways to use the marketing budget effectively.

• To present the findings through visualizations and an interactive dashboard.

##Tools and Technologies:

Python, Pandas, NumPy, EconML, DoWhy, SciPy, React.js, Plotly, Git and GitHub.

##Project Plan:

The project will be developed step by step over 20 days, starting with project understanding and data preparation, followed by analysis, model development, optimization, and dashboard development.
