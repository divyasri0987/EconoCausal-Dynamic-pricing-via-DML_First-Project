##EconoCausal – Dynamic Pricing via Double Machine Learning

## Project Introduction:

EconoCausal is a Data Science and Machine Learning project that focuses on understanding how discounts affect customer purchasing behavior. The main aim of this project is to find out whether offering a discount actually influences a customer's decision to buy a product. Using Causal Inference and Double Machine Learning (DML), the project will analyze the impact of discounts on purchasing decisions. It will also explore how businesses can distribute discounts effectively within a limited marketing budget and make better pricing decisions based on data.
