Day 5: Data Preprocessing

Data preprocessing is an important step in the EconoCausal – Dynamic Pricing via Double Machine Learning project. It involves preparing the dataset for further analysis by checking data types, handling missing values, identifying duplicate records, and ensuring data consistency. Proper preprocessing helps improve data quality and prepares the data for causal analysis and machine learning.

Key Activities:

Data Type Validation: Checking whether columns have appropriate data types.

Missing Value Handling: Identifying missing values and deciding how to handle them.

Duplicate Detection: Checking for duplicate records in the dataset.

Feature Selection: Identifying relevant variables related to discounts and customer purchasing behaviour.

Categorical Data Encoding: Converting categorical variables into numerical formats when required.

Data Consistency: Checking for invalid values and inconsistencies.

Data Preparation: Organizing the dataset for Exploratory Data Analysis (EDA) and Double Machine Learning.

Expected Outcome:
A well-organized dataset that can be used for further analysis, causal effect estimation, and discount budget optimization.
