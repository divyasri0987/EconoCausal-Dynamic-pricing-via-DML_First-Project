## Day 3: Dataset Cleaning and Preprocessing

Today, I worked on cleaning and preprocessing the dataset for the EconoCausal – Dynamic Pricing via Double Machine Learning project.
The main objective was to prepare the dataset for further analysis by checking missing values, identifying duplicate records, examining data types, and reviewing the overall data structure.
Data cleaning is an important step because it helps improve data quality and prepares the dataset for Exploratory Data Analysis (EDA) and further machine learning tasks.
The cleaned dataset will be used in the next stages of the project, including data visualization and causal effect estimation.
